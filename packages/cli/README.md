# @profullstack/wx93

Short links from the terminal for [wx93.me](https://wx93.me): shorten, list, stats, QR codes, bulk, an hqtui TUI and a stdio MCP server.

```sh
curl -fsSL https://wx93.me/install | sh     # or: npm i -g @profullstack/wx93
wx93 https://example.com/a/long/link
wx93 login        # OAuth 2.1 in the browser
wx93 ls | wx93 stats CODE | wx93 tui | wx93 mcp
```

Docs: https://wx93.me/docs · Source: https://github.com/profullstack/wx93.me · MIT
